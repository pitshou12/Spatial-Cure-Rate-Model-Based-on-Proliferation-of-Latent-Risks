SAS Code repository for the project "Spatial Frailty Cure rate Model Based on Proliferation of Latent Risks." The advancement of geographic information systems and associated software has enabled medical databases to integrate survival data on patients, facilitating the examination of spatial correlations. Medical experts and statisticians often focus on identifying variations in survival patterns by region or county to understand the potential factors that contribute to such spatial differences. Consequently, there has been a growing emphasis on developing survival models for spatial clustering and variation. Furthermore, as medical and health sciences progress rapidly, researchers increasingly encounter datasets in which many patients are cured. Models that accommodate cured individuals in the population help predict the outcomes of potentially terminal diseases. Our work proposes a Bayesian modeling framework encompassing spatial associations for areally referenced cure rate survival data using an innovative model that allows for the evolution of latent risks over time. The cure rates are modeled through a covariate link specification and the spatial frailties are specified using a Conditionally Autoregressive model (CAR). We illustrate our method and its advantages over existing methods by assessing the impacts of intervention in some patient-level covariates to mitigate existing racial disparity in breast cancer survival in 67 Florida counties (clusters) using the Florida Cancer Registry (FCR).

The repository contains the following code:

Bayesian analysis: illustrates our work using the data in the introduction and discusses how we tuned the computing algorithms.

Simulation study: an empirically evaluation and comparison of the model performance are used, considering sensitivity and robustness studies.
